DivTable Widget

A modern table widget built with CSS Grid and Flexbox — no HTML tables. Features grouping, sorting, filtering, virtual scrolling, and inline editing powered by Monaco Editor.

Table with Checkboxes

Multi-select rows via checkboxes. Supports grouping, filtering via query expressions, and aggregate columns (e.g. salary sum). A new record is added programmatically after 3 seconds.

const table = new DivTable(monaco, {
  tableWidgetElement: document.getElementById('divtable1'),
  data: data,
  columns: columns,
  showCheckboxes: true,
  multiSelect: true,
  showHeaderSummary: true,
  showGroupSummary: true,
  onSelectionChange: (rows) => { /* handle selection */ },
  onRowFocus: (row, group) => { /* handle focus */ }
});

// Apply a query filter
table.applyQuery('city = "Chicago" AND age > 26');

// Add a record programmatically
table.addRecord({ id: 14, name: 'New User', age: 22, city: 'Hamburg' });

Virtual Scrolling (1000+ Records) with Fixed Columns

Lazy-loads pages of 100 records as you scroll. First column is fixed. Grouped by department with sort on city. Includes auto-fetch and refresh buttons.

Row Details

Click on a row to see details here
const virtualTable = new DivTable(monaco, {
  tableWidgetElement: el,
  data: null,                           // Load first page via onNextPage
  columns: virtualColumns,
  group: 'department',
  sort: { field: 'city', direction: 'asc' },
  fixedColumns: 1,
  showCheckboxes: true,
  multiSelect: true,
  showGroupSummary: true,

  // Virtual scrolling configuration
  virtualScrolling: true,
  pageSize: 100,
  totalRecords: 1000,
  loadingThreshold: 20,
  showRefreshButton: true,
  showAutoFetchButton: true,
  autoFetchDelay: 500,

  onNextPage: async (page, pageSize) => {
    return await fetchData(page, pageSize);
  }
});

// Programmatic refresh
await virtualTable.refresh();

Component Features

Overview of what the DivTable widget provides.

CSS Grid Layout

No HTML tables — built entirely with divs, CSS Grid and Flexbox for maximum flexibility.

Virtual Scrolling

Lazy-loads pages of data as you scroll. Handles 1000+ records smoothly with configurable page sizes.

Grouping & Aggregates

Group by any column with collapsible headers. Supports sum, count and custom aggregate functions per group.

Query Filtering

Filter data with expressions like city = "Chicago" AND age > 26 — powered by the built-in query engine.

Fixed Columns

Pin columns to the left so they remain visible while scrolling horizontally through wide datasets.

Monaco Integration

Uses the shared Scooter.loadMonaco() singleton loader — no duplicate CDN loads, no race conditions.
