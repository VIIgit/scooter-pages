Service Health Registry

A dashboard for managing ~500 microservices with health monitoring, filtering, and multiple view modes.

Interactive Registry

Click on service cards to view detailed information. Use filters to narrow down services. Toggle between Grid, Grouped, and Treemap views using the buttons in the header. 

<!-- Service Health Registry -->
<div data-sc="service-health-registry" data-view="grid" data-detail-dialog="#demo-detail-dialog">
  <!-- Content auto-generated based on services data -->
</div>

<!-- Service Detail Dialog -->
<div data-sc="service-detail-dialog">
  <dialog data-slot="dialog-content">
    <!-- Content populated when service is selected -->
  </dialog>
</div>
// Get component references
const registry = document.querySelector('[data-sc="service-health-registry"]');
const dialog = document.querySelector('[data-sc="service-detail-dialog"]');

// Load services data (from API, mock generator, etc.)
const services = generateMockServices(500);
registry._serviceHealthRegistry.setStatusColors(STATUS_COLORS);
registry._serviceHealthRegistry.setServices(services);

// The linked detail dialog opens automatically on card click
registry.addEventListener('sc:select', (e) => {
  const service = e.detail.service;
  console.log('Selected:', service.name);
});

// Listen for filter changes
registry.addEventListener('sc:filter', (e) => {
  console.log('Filters:', e.detail.filters);
});

// Listen for view changes
registry.addEventListener('sc:view-change', (e) => {
  console.log('View:', e.detail.view);
});

// Programmatic control
registry._serviceHealthRegistry.setView('grouped');
registry._serviceHealthRegistry.setFilters({ region: 'EU-WEST' });
registry._serviceHealthRegistry.getFiltered(); // → filtered service array

// Dialog events
dialog.addEventListener('sc:open', (e) => {
  console.log('Dialog opened for:', e.detail.service.name);
});
dialog.addEventListener('sc:close', () => {
  console.log('Dialog closed');
});

Component Features

Overview of what the Service Health Registry provides.

🔍 Smart Filtering

Filter by region, exposure level, tier, interface type, and health status. Full-text search across service names.

📊 Multiple Views

Grid view for browsing, grouped view by deployment context, and treemap for status overview.

📋 Service Details

Click any service to see APIs, deployment context, health metrics, and golden rule compliance.

⚡ Mock Data

Auto-generates 500 realistic services with varied health states and deployment contexts.
