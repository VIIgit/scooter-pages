Tabs Component

Switch between content panels with keyboard-accessible tabs.

Basic Tabs

A simple tabs group with three panels.

Overview

Tabs organise content into separate views where only one view is visible at a time. Clicking a tab activates the corresponding panel.

Features

  • Arrow-key navigation between triggers
  • ARIA roles and states for screen readers
  • CSS-only styling — no inline styles
  • Supports default value via data-default-value

Usage

Add data-sc="tabs" to the root, data-slot="tabs-list" around the triggers, and data-slot="tabs-content" for each panel. Match trigger and panel via data-value.

Code Snippets

Tabs work well for showing alternatives side-by-side.

<div data-sc="tabs" data-default-value="tab1">
  <div data-slot="tabs-list" role="tablist">
    <button data-slot="tabs-trigger" data-value="tab1" role="tab">Tab 1</button>
    <button data-slot="tabs-trigger" data-value="tab2" role="tab">Tab 2</button>
  </div>
  <div data-slot="tabs-content" data-value="tab1" role="tabpanel">…</div>
  <div data-slot="tabs-content" data-value="tab2" role="tabpanel">…</div>
</div>
/* All tab styles come from base.css — no extra CSS needed.
   Override with custom properties if you want a different look. */
[data-slot="tabs-trigger"][data-state="active"] {
  color: var(--foreground);
  box-shadow: inset 0 -2px 0 0 var(--foreground);
}
